# Books: AI Reading Summaries

One file per chapter, named `author-book-chNN.md` (book abbreviation included
only for authors with more than one book here). See `../ai-summaries.md` for
the full index, provenance note, and per-reading format spec; see
`../checklist.md` for per-document status.

- `munzner-chNN.md` — *Visualization Analysis and Design*, ch. 1–14 (all
  chapters assigned in any module; ch. 15 case studies and ch. 16 bibliography
  not summarized). Chapters 4, 6, 8–14 include a "Figures worth borrowing"
  field; the earlier five (1, 2, 3, 5, 7) predate that field — their
  "Memorable specifics" list key figures instead.
- `cairo-fa-chNN.md` — *The Functional Art*, preface+ch. 1, 2, 3, 4, 5, 6.
  `cairo-ta-*` — *The Truthful Art*, intro (ch. 0), ch. 1, 2, 5. Complete for
  all chapters assigned in any module; the 2026-07-18 additions (FA 4–6, TT
  0–2) include a "Figures worth borrowing" field.
- `tufte-*` — *The Visual Display of Quantitative Information* ch. 1–2 (`vdqi`),
  *Envisioning Information* ch. 3, 5 (`ei`), *Visual Explanations* ch. 2
  (`ve`), *Beautiful Evidence* ch. 5–6 (`be`), plus the standalone essay
  `tufte-powerpoint.md` ("The Cognitive Style of PowerPoint"). Read from PDFs
  in `_lecture_experiment/CS765-25 Readings/Tufte - Book Chapters/`.
- `ware-chNN.md` — *Visual Thinking for Information Design*, all 10 chapters
  (ch. 11 is just the index and was not summarized). Read from the
  uncorrected-proof PDFs in `_lecture_experiment/CS765-25 Readings/Ware -
  Visual Thinking for Information Design/` (`ware01.pdf`–`ware10.pdf`).
- `other/` — books we have only a single chapter for, e.g. `wexler-ch01.md`
  (Wexler, Shaffer & Cotgreave, *The Big Book of Dashboards*, ch. 1). Add
  future one-off book chapters here rather than starting a new top-level
  prefix for a book with just one entry.
